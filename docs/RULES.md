# ええやん　遊び方

思わず「ええやん！」と言わせたら勝ち。配られた3枚の言葉で売り込む、営業トーク対戦ゲームです。

---

## どんなゲーム？

「この〇〇を〇〇円で売ってください」というお題に対して、配られた3枚の言葉カードを使って、口頭で売り込みます。

親が「いちばん買いたくなった」トークをした人が1点。**最初に3点を取った人が優勝**です。

## 用意するもの

- 2〜8人
- 1人1台のスマートフォン
- 全員が同じ場所にいるか、ビデオ通話でつながっていること

トークはアプリではなく、声に出して行います。アプリは、お題やカードの配布、進行、タイマー、得点を担当します。

## はじめかた

1. 1人が「部屋つくる」でルームを作ります（この人がホストです）。
2. ほかの人は、表示されたQRコードを読み取るか、ルームコードを入力して「まぜてー」で参加します。
3. 2人以上そろったら、ホストが「はじめよか」を押します。

## 1ラウンドの流れ

1. **親が決まる**
   最初のラウンドはランダムで決まります。その後は参加した順に交代します。
2. **お題が出る**
   全員の画面に、同じお題（売る商品）が表示されます。
3. **カードが配られる**
   親以外の人に、言葉カードが3枚ずつ配られます。ほかの人の手札は見えません。
4. **準備時間（ふつうは90秒）**
   - 3枚を好きな順に並べ替えて、トークの流れを考えます。
   - 手元メモは自分にしか見えません。
   - 準備ができたら「いけるで！」を押します。全員が押すと、時間を待たずに次へ進みます。
5. **プレゼン（1人ふつうは60秒）**
   - 親の次の人から順番に、1人ずつ売り込みます。
   - 発表中の人のカード3枚が、並べた順に全員の画面に表示されます。
   - **3枚すべてをトークの中で使ってください。** カードとカードの間には、自分の言葉を自由に挟んでかまいません。
   - 時間切れになるか、「以上です！」を押すと次の人に代わります。
6. **判定**
   - 親は、いちばん買いたくなったトークを**1つだけ**選んで「ええやん！」を押します。
   - どれも買いたくならなければ「該当なし」も選べます（誰にも点は入りません）。引き分けはありません。
7. **結果**
   選ばれた人に1点が入ります。誰かが目標点に届いたらゲーム終了です。届いていなければ、親を交代して次のラウンドへ進みます。

## オプションルール（ルームを作るときに設定）

| 設定 | はじめの値 | 選べる範囲 |
|---|---|---|
| 目標点 | 3点 | 1〜10点 |
| 準備時間 | 90秒 | 30〜300秒、または無制限 |
| プレゼン時間 | 60秒 | 30〜180秒、または無制限 |
| カード交換 | なし | ありにすると、準備時間中に1回だけ手札の1枚を山札と交換できます |
| 価格表示 | あり | お題に「〇〇円で」を付けるかどうか |
| カテゴリ分散配布 | あり | 手札の3枚が同じ種類に偏らないように配ります |

## 困ったとき

- **接続が切れた**：同じスマートフォンでページを開き直せば、同じプレイヤーとして戻れます。
- **発表の番に接続が切れていた**：そのラウンドの発表はお休みになります。
- **親の接続が切れて判定が止まった**：60秒たつと、ホストが代わりに判定できます。
- **ホストの接続が切れた**：参加した順が最も早い人が、自動でホストを引き継ぎます。
- **途中から参加したい**：ゲームが始まった後の参加はできません。次のゲームから参加してください。
- **人数が2人を下回った**：ホストが「続行する」か「終了する」かを選びます。

## 盛り上がるコツ

- こじつけ大歓迎です。言葉と言葉をどうつなぐかが腕の見せどころです。
- 親は「理屈より、なんか買いたくなった」で選んでかまいません。
- 変わった言葉のカードほど、使いこなせたときに盛り上がります。
